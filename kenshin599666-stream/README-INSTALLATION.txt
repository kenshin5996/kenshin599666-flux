ARCHIVES IRON MAN — SCÈNE CINÉMATIQUE 5 MINUTES

CE ZIP NE CONTIENT QUE LA PAGE /archives-iron-man/.
Il ne remplace pas app/page.tsx, layout.tsx, globals.css, ni aucune autre page du site.

INSTALLATION
1. Faites une copie de sauvegarde du projet.
2. Dans ce ZIP, prenez le dossier app/archives-iron-man/.
3. Copiez uniquement ce dossier dans le dossier app/ de votre projet Next.js.
4. Si votre projet possède déjà app/archives-iron-man/, remplacez uniquement cette page et sa feuille de style après sauvegarde.
5. Redémarrez le serveur de développement ou redéployez le site.

CONTENU
- Présentation des deux portes : Spider-Man et Wolverine.
- Saisons et épisodes issus des données du fichier page.tsx fourni dans la conversation.
- Lecteur vidéo intégré pour les épisodes ayant un identifiant vidéo.
- Scène dialoguée d'environ 5 minutes, lancée après un clic.
- J.A.R.V.I.S. : voix française masculine, réglage grave.
- Pepper (femme de Tony Stark) : voix française féminine si une voix féminine française est disponible sur l'appareil.
- Tony Stark : voix masculine synthétique de remplacement. Vos enregistrements peuvent être intégrés ensuite.

À SAVOIR SUR LES VOIX
La synthèse vocale utilise les voix installées dans Windows / le navigateur. Le choix masculin/féminin et le timbre exact ne peuvent pas être garantis sur tous les appareils. Cette version distingue les rôles et demande une voix française masculine pour J.A.R.V.I.S. et Tony, féminine pour Pepper. Elle ne peut pas restaurer à l'identique une voix personnalisée dont le fichier audio ou le code source n'a pas été fourni.

DURÉE
La scène est programmée pour occuper une fenêtre d'environ 5 minutes. Si la synthèse vocale termine les dialogues plus tôt, l'écran attend la fin de cette fenêtre avant de reprendre la visite. Le temps réel peut varier si l'appareil lit lentement.

SÉCURITÉ VIDÉO
Le protocole affiché est une mise en scène visuelle. Il ne modifie pas réellement les permissions des vidéos. La confidentialité doit être réglée sur l'hébergeur vidéo et, si nécessaire, côté serveur.
